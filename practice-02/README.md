## Задание 1

Исправлен пропущенный `return` в стрелочной функции: `square(4)` возвращает число `16`.

Ключевые результаты экспериментов:
- `sum(2, 3)` → 5;
- `sum("2", 3)` → "23";
- присваивание объекта второй переменной сохраняет одну ссылку;
- spread массива создаёт новый массив, но не копирует вложенные объекты;
- порядок spread свойств влияет на итоговое значение;
- параметр по умолчанию применяется при отсутствии аргумента и при `undefined`, но не при `null` и пустой строке.

## Задания 2–4

В `src/task-service.js` реализованы все девять функций с валидацией и контрактами из методички:
- создание и нормализация задачи;
- поиск через `find`;
- выборка через `filter`;
- названия через `map`;
- расчёт статистики;
- добавление, изменение статуса, переименование и удаление;
- защита входных массивов и объектов от мутации.

При ошибках возвращается `{ ok: false, error }`. Успешные операции изменения возвращают новый массив; изменённая задача также создаётся как новый объект.

## Задание 5

`src/main.js` выполняет общий сценарий:
1. исходный набор;
2. добавление `id=20`;
3. выполнение `id=4`;
4. переименование `id=10`;
5. удаление `id=7`;
6. обработка дублирующего `id`;
7. демонстрация сохранности `demoTasks`.

Ожидаемые сводки: 50.0%, 40.0%, 60.0%, 60.0%, 75.0%.
