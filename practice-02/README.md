## 4. Модель данных и функции

Задача содержит четыре поля: положительный целочисленный `id`, строковое `title`, логическое `completed` и приоритет `low`, `medium` или `high`. Новая задача создаётся с `completed: false`. Название очищается от пробелов по краям и должно иметь длину от 1 до 100 символов.

`data.js` хранит общий набор и данные варианта. `task-service.js` содержит функции работы с задачами и не выполняет вывод. `main.js` последовательно вызывает функции и показывает результаты.

При успехе функции возвращают объект с `ok: true`, а при ожидаемой ошибке — `ok: false` и текст ошибки.

**Почему id не равен индексу:** индекс является текущей позицией элемента в массиве, а `id` — постоянным идентификатором записи. После удаления индексы могут измениться, а `id` остальных задач остаются прежними.

**Почему `getTaskStats` возвращает число, а не строку:** функция выполняет расчёт, а форматирование для вывода делается отдельно через `toFixed(1)`.

**Какие объекты копируются при изменении задачи:** создаётся новый массив и новый объект изменяемой задачи; исходные данные не изменяются.

## 5. Общий демонстрационный сценарий

| Этап | Ожидание: всего / выполнено / осталось / прогресс | Фактический результат | Итог |
|---|---|---|---|
| Исходный набор | `4 / 2 / 2 / 50.0%` | `4 / 2 / 2 / 50.0%` | Пройдено |
| Добавление id 20 | `5 / 2 / 3 / 40.0%` | `5 / 2 / 3 / 40.0%` | Пройдено |
| Выполнение id 4 | `5 / 3 / 2 / 60.0%` | `5 / 3 / 2 / 60.0%` | Пройдено |
| Переименование id 10 | `5 / 3 / 2 / 60.0%` | `5 / 3 / 2 / 60.0%` | Пройдено |
| Удаление id 7 | `4 / 3 / 1 / 75.0%` | `4 / 3 / 1 / 75.0%` | Пройдено |

**Идентификаторы итогового списка:** `[1, 4, 10, 20]`.

**Показанная ошибка:** повторное добавление `id = 20` возвращает ошибку `Задача с таким id уже существует`, состояние списка не изменяется.

**Подтверждение неизменности `demoTasks`:** исходный массив остаётся из четырёх задач, а исходная задача `id = 4` остаётся невыполненной.
