## 4. Задание 1. Запуск в Node.js и браузере

При запуске `hello.js` через Node.js вывод появляется в терминале. Последняя строка:

```text
Тип document: undefined
```

В браузере `typeof document` имеет значение `object`, потому что браузер предоставляет объект документа, а Node.js не создаёт HTML-страницу.

В программе также выводятся ФИО, группа, номер практической работы и вариант студента.

## 8. Задание 5. Отладка

После исправления программы получаются:

```text
Выполнено: 5
Осталось: 3
Контрольная сумма: 10
```

| Ошибка | Причина | Исправление | Результат |
|---|---|---|---|
| Вместо числа получался результат конкатенации строк | Значения были строками | Использовать `Number()` | `Выполнено: 5` |
| Контрольная сумма была неполной | Условие цикла не включало число 4 | Использовать `taskNumber <= 4` | `Контрольная сумма: 10` |
