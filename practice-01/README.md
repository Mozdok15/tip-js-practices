## Результаты

### Задание 1

В Node.js `typeof document` даёт `undefined`, потому что Node.js не предоставляет браузерный DOM. В браузере ожидается `object`.

### Задание 2

| Выражение | Значение | Тип |
|---|---:|---|
| `"8" + 2` | `"82"` | string |
| `"8" - 2` | `6` | number |
| `Number("8") + 2` | `10` | number |
| `"12" > "3"` | `false` | boolean |
| `12 === "12"` | `false` | boolean |
| `Number("")` | `0` | number |
| `Number("text")` | `NaN` | number |
| `Boolean("false")` | `true` | boolean |
| `typeof null` | `"object"` | string |
| `typeof NaN` | `"number"` | string |

### Задание 3

Для варианта 2 используется набор **15 задач**, из которых изначально выполнено **0**. Программа показывает 15 оставшихся задач, прогресс **0.0%**, статус «Не начато».

### Задание 4

Для варианта 2 дневной лимит составляет **4 задачи**. При 15 невыполненных задачах программа строит план на четыре дня: **4, 4, 4 и 3 задачи**.

### Задание 5

Исправление использует явное `Number()` и условие `taskNumber <= 4`. Итог: 5 выполнено, 3 осталось, контрольная сумма 10.
